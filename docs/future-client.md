# Future client contract (no npm package)

[Standalone browser functions](../examples/storage.js) use `await fetch`, `credentials:'omit'` and wildcard CORS. Key encoding is `~` plus unpadded canonical base64url of UTF-8; `~` is the empty key. Slashes, percent, Unicode and reserved delimiters are encoded inside a safe path segment. Never URL-decode the key token or use unchecked text as a backend prefix. List returns original decoded keys.

A future wrapper exposes asynchronous getItem/setItem/removeItem/clear/key/length. Key/value arguments are coerced with JavaScript `String`, including `undefined` -> `"undefined"` and `null` -> `"null"`. Unpaired surrogates should be rejected by a production wrapper rather than TextEncoder replacement; the server rejects invalid strings. `getItem` missing returns null; stored `"null"` is a string. JSON helpers stringify/parse, return `{found:false}` or `{found:true,value:null}`, propagate parse/serialization errors, and reject JSON.stringify's undefined result. BigInt/cycles throw; JavaScript numbers beyond 2^53-1 lose precision before reaching the service, so encode exact integers as strings. Embedded JSON whitespace is preserved.

Counting/indexing traverses paginated reads and can change concurrently; no snapshot or stable index guarantee. The local fake demo happens to serialize clear/list; the native adapter uses bounded non-snapshot pages and clear batches, and does not advertise whole-operation atomicity. A session helper may keep the namespace ID in sessionStorage; a persistent helper may use localStorage. Closing a tab does not reliably delete remote state. No synchronous API, origin isolation, native storage events, account identity or automatic encryption is promised.

Callers may encrypt locally with Web Crypto, then store base64 ciphertext as a string. Key management is the caller's responsibility. HTTPS protects transport only; random addresses and encryption do not prevent others from deleting/overwriting ciphertext. Ciphertext usually has poor compression. Avoid sensitive data in this public experimental service.

Serve this directory with `python3 -m http.server 8081 --bind 127.0.0.1`. Run the Java test-class demo on port 8080 as described in README. Separate ports are real browser origins. Before public launch, repeat against a configured HTTPS domain from an HTTPS origin; local HTTP CORS is not that launch drill.
